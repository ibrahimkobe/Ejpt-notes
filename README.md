# 🛡️ eJPT Study Notes

Personal study notes compiled while preparing for the **eLearnSecurity Junior Penetration Tester (eJPT)** certification. These notes cover core penetration testing methodology, from reconnaissance through exploitation, along with practical command references and lab walkthroughs.

> ⚠️ **Disclaimer:** These are personal study notes for educational purposes only. All techniques referenced are intended for use in authorized lab environments (e.g. INE labs, personal test labs) only. Do not use any of this information against systems you do not own or have explicit written permission to test.

## 🧭 Topics Covered

- **Reconnaissance** — passive & active information gathering, DNS recon, OSINT, Google dorking, Shodan
- **Footprinting & Scanning** — host discovery, Nmap port scanning, service/version detection
- **Enumeration** — FTP, SMB, HTTP, MySQL, SSH, SMTP enumeration via Metasploit auxiliary modules
- **Vulnerability Assessment** — manual & automated vuln scanning, Nessus, WMAP, EternalBlue, BlueKeep
- **Exploitation** — banner grabbing, Nmap NSE scripts, Metasploit exploit modules, payload handling
- **System & Host Based Attacks** — local privilege escalation and host-level attack techniques
- **Network Based Attacks** — SMB/NetBIOS, SNMP enumeration, pivoting, DNS/SMB relay attacks
- **Metasploit Framework (MSF)** — workspaces, database integration, auxiliary & exploit module usage
- **Web Application Pentesting** — HTTP method enumeration, Nikto, DIRB/Gobuster, WPScan, Burp Suite
- **Auditing Fundamentals** — core auditing concepts and methodology
